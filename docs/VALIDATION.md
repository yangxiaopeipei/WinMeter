# 0.1.0 发布检查

检查日期：2026-10-29。以下为本机验证结果，不代表所有电脑或硬件均已覆盖。

## 已完成

- 整理为标准源码仓库：src、src-tauri、scripts、tests、tools、docs；版本统一为 0.1.0。
- 应用、npm、Cargo 元数据指定 MIT；第三方原始许可证和声明单独保留。
- 固定 Tauri CLI 版本，保留 npm / Cargo 锁文件；官方 npm registry 审计报告 0 个漏洞（该结果仅针对 npm 依赖，不等同于全部组件的安全审计）。
- 前端测试 16 项通过；Rust 测试 45 项通过、2 项原有实机检查跳过。
- 在无预生成 runtime 的独立目录成功编译 C# 采集器，启动退出码 0，输出有效传感器快照。
- 检查传感器程序及 27 个 DLL 的 PE 静态导入，未发现另需打包的 VC++ 运行库导入；此检查不覆盖所有动态加载路径。
- 固定硬件 DLL 的 SHA256，构建前检查完整性；验证原始 LibreHardwareMonitor v0.9.6 下载包 SHA256 与记录一致。
- 安装包内置 WebView2 Evergreen x64 离线安装器，验证其 Authenticode 签名有效、签名者为 Microsoft Corporation。
- 安装器检查 Windows / x64 / .NET Framework 4.7.2+，阻止不符合条件的安装环境。
- 发布程序启用页面 CSP，删除禁用 SmartScreen 的浏览器参数；新用户默认不自动请求传感器管理员授权。
- 发布程序本机启动正常，仪表盘和 CPU 详情显示实时数据与曲线。
- 最终安装包在工作区中文路径下静默安装，退出码 0；安装后的主程序与已验证程序 SHA256 一致，31 个硬件资源文件及 MIT 许可证齐全。
- 安装后的程序可进入实时采集界面；卸载测试完成，原有传感器服务和用户自启配置保留。
- 便携 ZIP 的完整性检查通过；发布附件提供 SHA256SUMS.txt。
- 检查源码中常见密钥格式和本机用户绝对路径，未发现匹配；Git 忽略所有编译、依赖安装与测试输出。

## 仍需了解的限制

- 未在干净的 Windows 10 / Windows 11 虚拟机上完成验收。本机已有 WebView2、.NET Framework 和 PawnIO，不能据此声称“所有新电脑一次安装即通过”。尤其需要补测无 WebView2 且断网的安装场景。
- 部分 CPU 温度 / 风扇项目需要用户另外安装官方 PawnIO，并为传感器授权；基础监控不以此为前置条件。
- 安装器检查缺失的 .NET Framework，但不会代为修复被精简或损坏的系统组件。支持范围为 Windows 10 22H2 / Windows 11 x64。
- 可选温度服务作为独立组件运行；卸载主程序前需在设置中卸载服务，受保护的服务文件可手动清理。
- 未配置项目代码签名，安装包可能显示未知发布者。已验证的微软签名仅属于内置的 WebView2 安装器。
- 尚未对所有 Rust / .NET / 原生依赖执行专门的漏洞数据库审计或全量人工安全审计。
